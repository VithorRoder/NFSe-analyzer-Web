Baixar XMLs pelo ADN

Use o certificado digital selecionado no Chrome para baixar os documentos autorizados pela API oficial. A consulta percorre os NSUs do certificado e não usa os filtros da listagem do portal.

Ao escolher Emitidas ou Recebidas, o site identifica automaticamente a empresa se o mesmo CNPJ/CPF aparecer em todas as notas do lote. Você também pode informá-lo acima.

Até 5.000 documentos por ZIP. Se houver mais, continue a partir do NSU indicado.

Organizar um ZIP baixado do ADN

Selecione o ZIP para relacionar os eventos às notas e criar uma planilha com os XMLs organizados. Você também pode incluir uma representação em PDF de cada nota. Tudo é processado nesta aba.
