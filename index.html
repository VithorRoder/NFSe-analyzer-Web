Instalar pela Chrome Web Store ↗Como instalar o complemento ↗

Baixar XMLs pelo ADN

Use o certificado digital selecionado no Chrome para baixar os documentos autorizados pela API oficial. A consulta percorre os NSUs do certificado e não usa os filtros da listagem do portal.

O site identifica a empresa pelo CNPJ/CPF presente em todas as notas, inclusive ao escolher Emitidas e recebidas. Se houver mais de uma possibilidade, informe o documento para classificar a direção no XLSX e no visualizador.

A consulta percorre todos os NSUs autorizados e gera um único pacote consolidado ao terminar. Você pode interromper e salvar os XMLs já recebidos.

Consolidar ZIPs do ADN

Selecione todos os ZIPs da consulta ao ADN. O site confere a sequência dos NSUs, relaciona os eventos às notas entre os lotes e só então cria a planilha consolidada. Você também pode incluir PDFs de conferência. Tudo é processado nesta aba.

Selecione todos os ZIPs do ADN para começar.
